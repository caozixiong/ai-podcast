首先来看 arXiv 上一篇预印本论文，需要说明的是，预印本还没有经过同行评审。Alan W. Muriithi 等人提出了一种利用随机优化技术，特别是方差缩减的 X 射线叠层成像重建框架。叠层成像是一种无透镜相干衍射成像技术，传统算法在物体变大或分辨率提高时，计算和内存需求会急剧恶化。该框架采用具有衰减步长的随机梯度下降，通过逐步减少梯度噪声的影响来优化前向模型，并纳入了泊松最大似然公式和部分相干性。数值实验表明，在处理 200,000 张 128x128 像素的衍射图案时，该框架的重建质量在视觉上与现有方法相当，但峰值 GPU 内存使用率仅为原来的 65%，重建时间缩短至原来的 22%。

另一条来自 arXiv 的预印本论文，作者 Abdulaziz Alqahtani 等人研究如何改进 X 光行李图像中的实例分割。他们针对重叠投影和复杂轮廓导致的违禁品界定难题，在级联掩码区域卷积神经网络框架中引入了共享的点基掩码细化模块。该框架结合残差网络 101 主干与基于注意力的特征金字塔，将掩码分辨率从 28 x 28 提升至 112 x 112。在官方 PIXray 分割数据集上，使用 Transformer 和多層感知器两种变体进行评估。结果显示，Transformer 细化器的平均掩码 AP 为 71.79，相比未细化检测器的 70.50 提升了 1.29 个 AP 点；而 MLP 细化器达到了 72.47 的 AP，提升了 1.97 个 AP 点。虽然 MLP 变体取得了最高精度并改善了边界一致性，但文章指出检测诊断方面未确立相应的正向增益，且需要在独立数据集上验证泛化能力。

第三条消息来自 arXiv 预印本，Johannes Gruen 等人提出了名为 BeST 的方法，即 Beta 溅射断层扫描。传统相干 X 射线断层扫描需要高保真重构每个投影的相位，但单个投影的缺陷会导致断层重构不一致。BeST 通过直接耦合相位恢复和断层扫描，利用共同的物体体积强制一致性。它使用具有闭式解析投影的紧凑支持 beta 基元来表示物体体积，相比体素网格显著减少了可优化参数。该方法在硬 X 射线近场全息术和远场 ptychography 的实验数据集上进行了演示，结果显示联合技术相比两步法提高了重构质量。

接下来是 arXiv 上的一篇预印本，Fethi Harkat 等人提出了一种结合持续同调拓扑特征与卷积及图神经网络的混合架构，用于 X 射线多能谱超光谱图像分割。传统框架在处理多能 X 射线透射图像时面临高维冗余和非线性光谱重叠的挑战。该方法在 UMAP 投影的超像素点云上计算 Vietoris-Rips 持续同调，以捕获编码光谱异质性的 H 1 循环结构。拓扑描述符通过广播机制与像素级 CNN 特征结合，将超像素级图表示传播到全空间分辨率。实验结果显示，该混合模型在 XRT 多能图像上的性能显著优于仅 CNN 和超像素池化融合基线。

另一条来自 arXiv 的预印本，Chengxiang Wang 等人提出了一种基于点扩散函数的新型二维方向滤波反投影方法，用于改进锥形束旋转计算层析成像的重建质量。传统的 CL-FBP 和 CL-FDK 技术依赖沿探测器行的 1D 逐行滤波，常产生叠加伪影和边缘模糊。该方法通过推导投影过程的精确表达式，引入包含两个加权因子的修正反投影过程，并开发了一种近似方法，将 3D 图像空间滤波操作转移到 2D 投影空间。推导出的 2D 方向滤波器整合了 2D von Hann 窗和 2D sinc 窗。需要注意的是，该近似方法依赖于在某些假设下线性化傅里叶空间中的坐标关系。

最后一条 arXiv 预印本论文由 Maziar Raissi 等人撰写，研究指出匹配二维统计量并不能保证重构的三维电池电极结构具有正确的三维传输性能。他们使用可微分电导率求解器优化体素结构，使其在相分数、边界密度、两点和三点关联以及线径函数等统计量上与真实电极匹配。然而，发现的“统计孪生”结构比真实电极导电性低 10 到 88 倍，且对 5 的 3 次方多数滤波具有鲁棒性。相反，导电性最高的结构最多比真实电极高 3.3 倍。基于二维截面的分类器可以检测到这些统计孪生结构，表明信息存在于图像中而非统计量中。
